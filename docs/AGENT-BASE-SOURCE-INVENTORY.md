# Agent Base is Source Inventory

Skills Hub is the canonical atomic skill home. Agent Base remains the recoverable
source/extraction warehouse; it is not an automatic install or deletion list.

The 5 September 2026 Luna check found **79 valid definitions** under
`templates/profile/skills/`, plus `_archive` (not a definition). The earlier
120 count is retained as an unverified historical claim, not a target to invent
missing files for. The prior three-home count is 237 paths: 79 source definitions
and 158 repo-local compatibility copies, not 237 distinct skills or global user
installation evidence.

[Machine inventory](../registry/agent-base-source-inventory.json) records every
source path, current hash and provisional classification. All 79 current hashes
match the prior complete-SKILL.md reading; Luna rechecked them instead of repeating
unchanged reading. Referenced tools/resources and dependency behavior remain
unverified. No source was deleted, moved, installed or promoted by this pass.

Classification counts: 18 atomic capabilities, 5 mixed definitions, 24 playbooks,
3 private-environment recipes, 9 system adapters and 20 unverified definitions.
Composed workflows belong to Agent Playbook; runtime integrations retain their
own owners. Admission needs a scoped source/license review and behavior check,
not merely a classification label. The inventory does not change registry entries.
