# Rule: Verify Context Before Acting

Before starting any task, verify you understand the "Why".

## The Check

If you lose track of why you're doing something:

```bash
python3 .claude/skills/os-database/scripts/query_context.py
```

This returns: Task → Goal → Mission → Project hierarchy.

## When to Check

- Task seems unclear
- Multiple priorities conflict
- Starting a new subtask
- Before handoff

## Never

- Act without understanding the goal
- Skip context verification on complex tasks
