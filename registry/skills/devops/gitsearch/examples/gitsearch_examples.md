# GitHub Search Examples

## Search Repositories

```bash
/gitsearch react authentication library
```

## Search Code

```bash
/gitsearch useAuth hook React
```

## Search Issues

```bash
/gitsearch React 19 memory leak
```

## Search PRs

```bash
/gitsearch Next.js authentication
```

## Output Format

Returns:
- Repository name and URL
- Star count
- Brief description
- Relevance to query
