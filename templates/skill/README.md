# Skill Template

This is a template for creating new skills in the SISO Skills Hub.

## Usage

Copy this template to `registry/skills/<category>/<skill_name>/` and customize the files.

## Files

- `SKILL.md` - Main skill definition with frontmatter
- `README.md` - Documentation
- `install.sh` - Installation hook (optional)
- `uninstall.sh` - Uninstall hook (optional)
- `config/default.json` - Configuration (optional)
- `scripts/` - Executable scripts (optional)
- `examples/` - Usage examples (optional)
